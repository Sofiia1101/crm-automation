# crm-automation
Workflow automation using Make.com webhooks, filters, and Google sheets

Ситуація
CRM передає дані замовлення в Make через webhook. Потрібно відібрати підтверджене замовлення та підготувати його дані для подальшої передачі в Google Ads.

Що потрібно зробити
Створіть у Make сценарій, який:

1. Приймає дані замовлення через webhook.
2. Пропускає далі лише замовлення, у якого:
一 статус paid ○ заповнене поле gclid
3. Формує набір даних:
一 номер замовлення
○ gclid
○ дата і час події
○ сума замовлення
○ валюта
4. Записує ці дані в Google Таблицю.

Ціль  

CRM передає дані про замовлення в Make. Необхідно відокремити якісні конверсії від усіх отриманих замовлень та підготувати їх до подальшої передачі в Google Ads.

Для цього до наступного етапу мають потрапляти лише замовлення, які:

•мають статус paid;

•містять заповнений gclid. Умови
Якщо status = paid AND gclid заповнений , замовлення передається далі. В іншому випадку замовлення відфільтровується.

Послідовність інтеграції

CRM → Webhook → Filter → Google Sheets Webhook отримує дані про замовлення у форматі JSON.
Filter перевіряє бізнес-умови.

До Google Sheets передаються лише замовлення, які відповідають умовам.

У Google Sheets зберігаються необхідні дані для подальшої передачі в Google Ads.

Відповіді на питання

1. Як gclid може потрапити із сайту в CRM?
Під час кліку на рекламу Google параметр gclid додається до URL. Сайт зчитує та зберігає це значення і під час оформлення замовлення передає його разом із даними замовлення в CRM через форму або API.
 

2. Як запобігти повторній передачі одного замовлення?
Необхідно використовувати унікальний ідентифікатор замовлення (order_id) і перед передачею перевіряти, чи оброблялося це замовлення раніше. Для цього можна використовувати Data Store у Make або зовнішню базу даних для зберігання ID уже оброблених замовлень.

 

3. Що перевіряти, якщо дані вийшли з CRM, але не дійшли до Google Ads?
Історію  виконання сценарію в Make, щоб визначити етап, на якому виникла помилка.  Коректність даних, mapping та результат API-запиту до Google Ads, включно з gclid і налаштуваннями підключення.
